# BM25 Ranking

BM25 is a probabilistic ranking function for keyword search. Given a query and a document, it scores how relevant the document is by summing a contribution from each query term. It has been the default baseline in information retrieval for decades and remains a strong component of hybrid retrieval systems.

Each term's contribution has two parts. The inverse document frequency (IDF) rewards rare terms: a word that appears in only a few documents carries more information than one that appears everywhere, so common words are nearly ignored. The term frequency (TF) part rewards documents that mention the term more often, but with saturation: the second occurrence helps less than the first, and the tenth barely helps at all. The parameter k1, typically between 1.2 and 2.0, controls how quickly this saturation happens.

BM25 also normalizes for document length. A long document mentions many words simply because it is long, so its term frequencies are discounted relative to the average document length. The parameter b, usually 0.75, sets how strong that length normalization is; b = 0 disables it entirely.

Implementing BM25 requires an inverted index that maps each term to the list of documents containing it along with the term counts, plus the length of every document. Query time is proportional to the size of the posting lists for the query terms, which makes it fast even over millions of documents.

Compared with dense embeddings, BM25 excels at exact matches on rare tokens such as product codes, error messages, and names, and it needs no training. It struggles with synonyms and paraphrase, which is why many systems combine lexical and semantic retrieval.
